A deterministic long-only paper-trading bot for the agent-fun/bars-replay/v1 hourly Solana replay. It ranks the seven symbols with EMA trend, 12/24-hour momentum, volatility-normalized scores, dip-rebound entries in uptrends, regime-adaptive gross exposure, and trailing/time exits. Paper trading only; no real funds, no network, no randomness.

## Run it

```sh
node main.ts
```
